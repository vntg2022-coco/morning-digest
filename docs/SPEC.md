# Good Morning Digest — サービス仕様

2026-10 時点の合意内容。元になったのはオーナーの手書きノート(サービスの流れ・画面スケッチ・機能メモ)と、それに続くQ&A。

## コンセプト

毎朝、学びたい言語で書かれたニュースが届く語学サービス。母国語の対訳つきで読み、わからない単語はその場で調べて単語リストに貯めていく。

キャッチコピー: **"Language learning is the key to connecting with the world."**(言語学習は世界とつながるカギだ。)

## 対応言語(12)

英語 / 中国語 / ヒンディー語 / スペイン語 / フランス語 / ロシア語 / ポルトガル語 / ウルドゥー語 / インドネシア語 / ドイツ語 / 日本語 / 韓国語

- ユーザーは12言語から**母国語を1つ**選ぶ。
- 残りの11言語から**学習言語**を追加する。学習言語ごとにレベル(初級・中級・上級)を設定する。
- 対訳は「学習言語 | 母国語」の2列で表示する。
- **学習言語は削除できない。** 設定画面では、Macの「優先する言語」のように学習言語が1本のリストに並ぶ。上から順にプランの枠の数(スタンダード1・プレミアム3、追加購入1つにつき+1)までが有効(一番上がPrimary)、線より下は休止中。行をドラッグして並べ替える。有効な言語が線の下に押し出される並べ替え(=入れ替え)は**30日に1回まで**。有効な言語どうしの並べ替えと、空き枠への追加はいつでもできる。「+」で追加、「−」はない。レベルと母国語はいつでも変えられる。
- 休止中の言語には新しい記事が届かないが、過去の記事と単語リストは見られる。プラン変更で枠が減った場合は、リストの上から順に枠に入り、残りは休止扱いになる。
- サイトの表示言語(メニュー・ボタン・LP)は**英語のみ**で始める。多言語化は後から追加する。

## 毎日の流れ

1. 毎朝ユーザーが選んだ時刻(初期値は現地時間の6:00)に、メールで「今日のニュースが届いた」と知らせる。
2. メールのリンクから、Webの **News box** に移動する。
3. Webでニュースを読む。

- メールの中身は**お知らせ+今日の3本の見出し+リンク**のみ。記事本文はWebで読む。
- 毎日、学習言語×レベルごとに**3本**の記事が届く。

## 記事ページ

- 左に学習言語、右に母国語の対訳を並べる。
- 文中の単語をクリックすると、**意味と例文**(母国語)が表示される。
- クリックした単語は、サイドバーの**単語リスト**に貯まる(プレミアムのみ)。
- スタンダードにも単語リストのサイドバーは見えるが、ロックされている。これをプレミアムへの誘導にする。
- 過去の記事はアーカイブに貯まり、あとから読み返せる。スタンダードがアーカイブで読めるのは、その日に選んだ1本だけ。選ばなかった2本は後からも読めない。

## プランと料金

**無料プランはない。** 登録するとカードなしで「お試しの1日」(次の朝の配信まで、プレミアムと同じ機能で、その日の3本を読める)が使える。続けるには7日間の無料トライアル(カード登録)を始め、その後スタンダードかプレミアムに課金する。登録した日にその人の組み合わせの記事がまだなければ、その場で作る(1〜3分)。

| | スタンダード | プレミアム |
|---|---|---|
| 月額 | **$4.99** | **$9.99** |
| 1日に読める記事 | 3本のうち1本を選ぶ | 3本すべて |
| 単語リスト | なし(サイドバーにロック表示) | あり |
| 学習言語 | 1言語 | 3言語まで追加料金なし |

- **無料トライアル**:登録時にカードを登録し、最初の**7日間はプレミアムの全機能**を無料で使える。終了時に、選んだプラン(スタンダードかプレミアム)で課金が始まる。
- **言語の追加購入**:プランの上限を超えて学習言語を増やすときは、1言語ごとに**買い切り**で購入する。月額は変わらない(1言語 **$4.99**)。
- プランはあとから変更できる。

## ランディングページ(上から順に)

1. **ヒーロー**:新聞のコラージュを背景に、アンティーク調の郵便ポストとキャッチコピーを置く。カギをタップすると、カギが鍵穴に刺さるアニメーションが流れ、サインイン/ログインに進む。ポストとカギの絵は、最初は仮のSVGで作り、あとで本番の絵に差し替える。
2. **対訳つき**:2列の対訳の見本。「わからない単語をすぐに確認できる」。
3. **12言語対応**:言語のバッジを散らしたデザイン。
4. **サンプル**:言語を切り替えて、実際にどう見えるかを試せる。
5. **利用者の声**:枠だけ用意して**非表示**にしておく。本物の声が集まったら表示する(架空の声は載せない)。
6. **料金**:スタンダードとプレミアム。
7. **締め**:もう一度ポストとキャッチコピー。

## 技術構成

| 役割 | 使うもの |
|---|---|
| Web | Next.js(Vercel) |
| ログイン・DB | Supabase |
| ニュース取得 | GNews(公開時に Essential プラン) |
| 要約・翻訳・単語の意味 | Claude API |
| メール | Resend |
| 課金 | Stripe(サブスク+トライアル+買い切り) |
| 毎朝の実行 | Vercel Cron |

### 記事づくりの費用を抑える仕組み

母国語12 × 学習言語11 × レベル3 = 396通りを毎日全部作ると、月800ドルを超える。そこで次のようにする。

- **登録ユーザーがいる組み合わせだけ**を毎日作る。
- 学習言語での記事本文は「学習言語×レベル」ごとに1回だけ作る。母国語への対訳と単語の意味は、その組み合わせごとに追加で作る。
- 単語の意味と例文は記事を作るときにまとめて用意しておき、クリック時に追加でAIを呼ばない。

6. **Stripe課金**(トライアル・2プラン・言語の追加購入)
7. **独自ドメインとメール送信元の設定、公開**
